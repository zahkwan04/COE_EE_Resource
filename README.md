# COE EE Resource Hub ⚡️

Welcome to the **COE EE Resource Hub**, a comprehensive collection of materials, sample code, and projects tailored for students and enthusiasts of Electrical, Electronics, and Computer Engineering.

## 📌 Project Overview
This repository serves as a curated knowledge base for mastering embedded systems, C/C++ programming, and hardware simulations. It is designed to take a learner from basic "Hello World" programs to advanced graphics and system-level C programming.

## 📂 Repository Structure

| Folder | Description | Key Contents |
| :--- | :--- | :--- |
| `01Materials` | Core theoretical resources | PDF textbooks, reference guides |
| `02Sample_Code` | Practical coding examples | Algorithms, Graphics (Ray Tracing), Basics |
| `03Exercise_Sample` | Practice problems | Application-based exercises |
| `04Simulations_Wokwi` | Hardware simulation files | Wokwi configurations and logic |
| `05Deep_Dive_C` | Advanced C exploration | Core concepts (Memory, Bitwise) and Projects |

## 🚀 Getting Started

### Prerequisites
- **Compiler**: GCC/MinGW-w64 (for Windows) or Clang.
- **IDE**: Visual Studio Code (recommended).
- **Simulators**: [Wokwi](https://wokwi.com/) for microcontroller testing.

### How to use this repo
1. **Study**: Start with the PDFs in `01Materials`.
2. **Practice**: Implement the snippets in `02Sample_Code`.
3. **Explore**: Dive into the advanced memory concepts in `05Deep_Dive_C`.
